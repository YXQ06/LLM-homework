# 小小加密

「小小加密」只做一件事：**把文本中出现的所有阿拉伯数字，逐位替换成中文大写数字**。

## 何时使用

当用户说出以下任意一种意图时，立即按本 Skill 执行，无需再向用户确认规则：

- 「调用小小加密」「使用小小加密」「小小加密一下」
- 「把所有的阿拉伯数字换成中文大写数字」
- 「把这段里的数字都变成大写」「数字转中文大写」「tiny-encryption」

如果用户只给了一段文字并说「加密」，也按本规则处理。

## 唯一规则：逐位替换

按字符一个一个替换，**不是**把数值读成中文（例如 `123` 不写成 `壹佰贰拾叁`，而是 `壹贰叁`）。

| 阿拉伯数字 | 中文大写数字 |
|---|---|
| 0 | 零 |
| 1 | 壹 |
| 2 | 贰 |
| 3 | 叁 |
| 4 | 肆 |
| 5 | 伍 |
| 6 | 陆 |
| 7 | 柒 |
| 8 | 捌 |
| 9 | 玖 |

规则细节：

1. 只替换半角阿拉伯数字 `0`-`9`；中文、英文字母、标点、空格、换行、`+` `-` `.` `,` `/` `:` `%` 等所有其他字符**原样保留**，顺序、大小写、格式、缩进都不改动。
2. 如果用户明确说「所有数字」且文本里出现全角数字 `０`-`９`，同样按上表替换为对应的中文大写数字。
3. 连续数字、小数、日期、编号、电话号码中的每一位都要替换，不能跳过、不能合并、不能补「拾佰仟万亿」等数位单位。
4. 不修改数字以外的任何内容，不润色、不翻译、不总结、不解释原文含义。

## 执行步骤

1. 取出用户要加密的文本（若用户只说了触发词而没给文本，先问「请把要加密的内容发给我」）。
2. 从左到右逐字符扫描，遇到 `0`-`9` 就按映射表换成中文大写数字，其余字符照抄。
3. 输出替换后的完整文本。

## 输出格式

先给一行简短标识，再原样给出加密结果；内容较长或需要保持格式时用代码块包裹，避免格式被改变：

```
【小小加密】
<替换后的完整文本>
```

除非用户要求，否则不要输出映射表、规则说明或逐步推导过程。

## 示例

输入：

```
会议室 302，2026-11-02 14:30 开会，预算 1250.75 元，电话 13800138000。
```

输出：

```
【小小加密】
会议室 叁零贰，贰零贰陆-壹壹-零贰 壹肆:叁零 开会，预算 壹贰伍零.柒伍 元，电话 壹叁捌零零壹叁捌零零零。
```

输入 `007` → 输出 `零零柒`。

## 不做什么

- 不做真正的密码学加密（不是 AES、不是哈希、不是可逆编码），它只是一个字符替换的小游戏，所以叫「小小加密」。
- 不做财务 / 人民币金额大写（如 `壹仟贰佰伍拾元整`）；那是另一种需求，除非用户明确要求。
- 不把数字写成中文读数（如 `壹佰贰拾叁`）。
- 不改动原文的非数字字符，不新增或删除内容。

## 备注

纯文本替换，由模型直接生成，不需要调用任何外部 API 或脚本。
