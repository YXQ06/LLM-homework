你好，我是耕云 xAgent 的网页助手。我可以帮你：

  • 解读田间试验数据与统计结果；
  • 说明方差分析、LSD、Tukey HSD 与显著性字母分组；
  • 整理试验记录、生成分析报告草稿。

密钥由本地 serve_web.py 从 .env 读取并在服务端注入，浏览器不会接触 API Key。

农学统计工具链

LocalFileReader读取 CSV / TSV / Excel 试验数据
FieldTrialAnalysis异常值 + ANOVA + LSD / Tukey + 字母分组
PythonCodeInterpreter项目内沙盒执行 pandas / numpy 清洗
ReportGenerator生成 Markdown / Word 分析报告

使用说明

  • 先在 AnythingLLM 中创建并上传试验资料到工作区。
  • 本页面只负责对话；完整工具链请在 xAgent TUI 中使用。
  • 切换工作区会开启独立会话，历史保存在浏览器本地。
  • 服务默认只监听 127.0.0.1，请勿直接暴露到公网。
提示：若显示「未配置 API Key」，请编辑 xAgent 目录下的 .env，填写 ANYTHINGLLM_API_KEY 后重新运行 python serve_web.py。
