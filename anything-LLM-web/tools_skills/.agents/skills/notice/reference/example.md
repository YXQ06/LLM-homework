## 财务部关于2027年元旦放假安排的通知
公司各部门、全体员工：

根据国务院办公厅节假日安排的有关规定，结合公司实际情况，现将2027年元旦放假安排通知如下：

一、放假时间

2027年1月1日（星期五）至1月3日（星期日）放假，共3天。1月4日（星期一）正常上班。

二、注意事项

1. 各部门要妥善安排好节日期间的值班和安全保卫工作，遇有重大突发事件，须按规定及时报告并妥善处置；
2. 放假前请各部门关好门窗，关闭电脑、打印机、空调等电器设备电源，切实做好防火、防盗工作；
3. 节日期间请注意人身和财产安全，合理安排出行计划；
4. 如节日期间有紧急财务事务，请提前与财务部联系对接。
祝全体员工元旦快乐，阖家幸福！
